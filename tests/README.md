# Verification

This folder contains scripts of the run_simulation.py script with the parameters used in the original paper by Hartzell and Akin, 2019. The scripts are used to run the simulation for specific scenarios and compare the results with the expected behavior shown in the original paper. The results are then compared visually to the expected behavior shown by the original paper.

`plasma_potential_analysis.py` quantitatively compares the normalised plasma potentials from the hartzell and Akin, 2019 paper with the results from the simulation code which uses teh bretqu method to solve the equation.
